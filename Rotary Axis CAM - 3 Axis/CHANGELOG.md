# Changes

## 1.6.0 — 2026-10-09

Added non-destructive STL centring and alignment, manual XYZ rotation and automatic long-axis estimation. Preview and CAM share one preparation routine and loaded source mesh. Placement changes invalidate displayed toolpaths. Added transformation, GUI state and end-to-end G-code regression tests.

## 1.7.0 — 2026-10-18

Opaque STL display, uniform cutting-path lines without point markers, and optional roughing generation. Finishing-only jobs skip roughing calculations and use the finishing cutter end inset.

## 1.8.0 — 2026-10-18

Independent low/high-X free-end finishing, radial depth-limited passes to Minimum Z, tip-radius axial overrun, and tapered-cutter warning. Original work zero and roughing end clearance retained.
